Project Objective

This project demonstrates the implementation of an automated Continuous Integration and Continuous Deployment pipeline using DevOps practices.


The system automatically takes source code from GitHub, builds and packages the application using Docker, publishes the container image to Docker Hub and deploys the application into a Kubernetes cluster.


Prometheus and Grafana are integrated for monitoring, while Alertmanager provides automated Gmail notifications when predefined monitoring conditions are satisfied.

Version 1 → Version 2 Upgrade

This page represents Version 2 of the application. The upgrade was deployed using the automated CI/CD pipeline.


When the source code is modified and pushed to GitHub, Jenkins automatically detects the change and starts a new pipeline execution.


Jenkins creates a new Docker image, pushes the image to Docker Hub and updates the Kubernetes deployment.


Kubernetes performs a rolling update so that the new application version becomes available without manually redeploying the application.
