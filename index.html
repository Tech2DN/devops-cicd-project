Automated CI/CD Pipeline

DevOps Final Year Project

Automating Build, Test and Deployment using Jenkins, GitHub and AWS

Project Overview

This project demonstrates an automated Continuous Integration and Continuous Deployment (CI/CD) pipeline. The application source code is maintained in GitHub and Jenkins automatically detects code changes, retrieves the latest source code, performs the required build and testing activities, and deploys the application to the target environment.

Jenkins Pipeline Stages

1. Source Code Checkout

Jenkins obtains the latest project source code from the GitHub repository.

2. Build

The application is prepared and built automatically as part of the pipeline.

3. Test

Automated checks can be executed to verify the application before deployment.

4. Deployment

The successful build is deployed to the configured server/environment.

Key Features

  • Automated CI/CD pipeline using Jenkins.
  • GitHub repository for source-code management.
  • GitHub Webhook integration for automatic pipeline triggering.
  • Pipeline configuration using a Jenkinsfile.
  • Deployment on an AWS Ubuntu environment.
  • Reduced manual deployment effort.
  • Faster and more consistent software delivery.
